OpenChaoJi EVCC HAL 移植、初始化与接口说明文档

本设计文档旨在指导软件工程师将 OpenChaoJi EVCC（电动汽车通信控制器）协议栈移植到目标硬件平台上。HAL（硬件抽象层）隔离了上层协议栈与底层微控制器的硬件外设（如 CAN、ADC、GPIO、RTC 及 OS 延时等）。

1. 核心数据结构定义

在移植和实现 HAL 接口之前，请先确保以下数据结构在您的代码中定义一致。

1.1 CAN 标识符与报文定义 (union can_id_t & struct can_pdu)

OpenChaoJi 的 CAN 通信遵循类似于 SAE J1939 标准的 29 位扩展帧格式。

1.2 电压电流采样结构体 (struct OpenChaoJi_evcc_hal_samp)

用于向协议栈上报充电回路的实时电压和电流测量值。

2. 协议栈初始化与主任务流

此部分定义了 EVCC 模块的生命周期，规定了系统如何初始化硬件和协议栈，以及如何在主任务循环中维持状态机运行。

2.1 初始化流程 (evccAppInit)

在系统启动或进入充电管理前，必须调用初始化函数。标准初始化流程如下：

  • evcc_hal_one_init() 移植说明：
    移植者需在此函数中实现硬件底层初始化，包括初始化 MCU 的 CAN 控制器、GPIO 配置（继电器控制引脚、电子锁控制引脚等）、ADC 通道配置、定时器，并使能相关中断。

2.2 任务轮询与服务执行 (evccAppTask)

该任务函数需放入系统的周期性任务、线程（Thread）或主循环中轮询执行。轮询周期通常推荐为 10ms ~ 50ms。

3. CAN 通信接口

3.1 OpenChaoJi_evcc_hal_information_recv_can_voluation

  • 接口原型：
    int OpenChaoJi_evcc_hal_information_recv_can_voluation(OpenChaoJi_hal_handle handle, struct can_pdu * can_recv_info)
  • 功能描述：
    从系统的接收缓冲区获取一帧已收到的 CAN 报文，并填充到协议栈中。
  • 参数说明：
    • handle：HAL 实例句柄。
    • can_recv_info：指向 struct can_pdu 的指针。移植者需要将底层驱动接收到的数据完整地映射到该结构体中。
  • 返回值：
    • 1：成功接收到一帧报文，并且数据有效。
    • -1：无新数据或接收失败。
  • 移植说明：
    需要调用目标平台 CAN 控制器的接收函数。由于底层接收多采用中断或 FIFO 机制，建议通过此函数轮询接收队列。确保底层的 29 位扩展 ID 解析能够正确拆分并映射到 can_id_t 联合体的各个位域中。

3.2 OpenChaoJi_evcc_hal_information_send_can_voluation

  • 接口原型：
    int OpenChaoJi_evcc_hal_information_send_can_voluation(OpenChaoJi_hal_handle handle, const struct can_pdu * can_send_info)
  • 功能描述：
    通过物理 CAN 发送一帧协议栈生成的报文。
  • 参数说明：
    • handle：HAL 实例句柄。
    • can_send_info：指向待发送报文 struct can_pdu 结构体的常量指针。
  • 返回值：
    • 0：发送成功。
    • 其他值：发送失败。
  • 移植说明：
    需调用目标平台的 CAN 发送接口。发送时应提取 can_send_info->can_id.uint32_tWord 作为发送 ID（配置为扩展帧发送），并将 can_dlc 与 data 写入物理发送邮箱。

4. 继电器与硬件开关控制接口

4.1 OpenChaoJi_evcc_hal_gbt_close_dc_relay

  • 接口原型：
    void OpenChaoJi_evcc_hal_gbt_close_dc_relay(OpenChaoJi_hal_handle handle, unsigned char ctl)
  • 功能描述：
    控制车辆端直流正极和负极主接触器的闭合与断开。
  • 参数说明：
    • handle：HAL 实例句柄。
    • ctl：控制命令，0-断开，1-闭合。
  • 移植说明：
    移植者需要在此处实现高压接触器（C5/C6 或对应的主正、主负继电器）驱动管脚的 GPIO 控制逻辑，或通过车载内网发送对应的闭合/断开指令。

4.2 OpenChaoJi_evcc_hal_gbt_b_lock (B类系统专用)

  • 接口原型：
    void OpenChaoJi_evcc_hal_gbt_b_lock(OpenChaoJi_hal_handle handle, unsigned char ctl)
  • 功能描述：
    控制物理电子锁进行锁止或解锁操作。
  • 参数说明：
    • handle：HAL 实例句柄。
    • ctl：0-解锁，1-锁止。
  • 移植说明：
    需控制车辆充电座上电子锁的电机或电磁铁驱动电路。注意某些电子锁采用脉冲驱动，通常需要在该函数内产生特定宽度的控制脉冲，或触发底层的脉冲输出任务。

4.3 OpenChaoJi_evcc_hal_gbt_b_close_s2 (B类系统专用)

  • 接口原型：
    void OpenChaoJi_evcc_hal_gbt_b_close_s2(OpenChaoJi_hal_handle handle, unsigned char ctl)
  • 功能描述：
    控制辅助开关 S2 的通断状态。
  • 参数说明：
    • handle：HAL 实例句柄。
    • ctl：0-断开，1-闭合。
  • 移植说明：
    将此接口映射到控制辅助开关 S2 对应继电器或开关元件的控制引脚。

4.4 OpenChaoJi_evcc_hal_gbt_b_close_s2p (B类系统专用)

  • 接口原型：
    void OpenChaoJi_evcc_hal_gbt_b_close_s2p(OpenChaoJi_hal_handle handle, unsigned char ctl)
  • 功能描述：
    控制辅助开关 S2p 的通断状态。
  • 参数说明：
    • handle：HAL 实例句柄。
    • ctl：0-断开，1-闭合。
  • 移植说明：
    映射到控制 S2p 相应开关回路的硬件驱动管脚。

4.5 OpenChaoJi_evcc_hal_gbt_b_close_sv (B类系统专用)

  • 接口原型：
    void OpenChaoJi_evcc_hal_gbt_b_close_sv(OpenChaoJi_hal_handle handle, unsigned char ctl)
  • 功能描述：
    控制辅助电源开关 Sv 的通断状态。
  • 参数说明：
    • handle：HAL 实例句柄。
    • ctl：0-断开，1-闭合。

5. 状态监测与硬件反馈接口

5.1 OpenChaoJi_evcc_hal_get_status_dc_relay

  • 接口原型：
    unsigned char OpenChaoJi_evcc_hal_get_status_dc_relay(OpenChaoJi_hal_handle handle)
  • 功能描述：
    获取直流正负主接触器的实际闭合/断开反馈状态。
  • 返回值：
    • 0：正、负极均断开。
    • 1：负极闭合，正极断开。
    • 2：正极闭合，负极断开。
    • 3：正、负极均闭合。
  • 移植说明：
    需配置并读取检测继电器辅助触点（如反馈引脚）的 GPIO 输入电平，然后将其转换为对应的返回值格式。

6. 模拟量采样接口

6.1 OpenChaoJi_evcc_hal_sampling_value

  • 接口原型：
    int OpenChaoJi_evcc_hal_sampling_value(OpenChaoJi_hal_handle handle, struct OpenChaoJi_evcc_hal_samp *samp_value)
  • 功能描述：
    一次性获取充电主回路的三个核心采样参数：输入电压、输出电压和电流。
  • 参数说明：
    • handle：HAL 实例句柄。
    • samp_value：指向目标采样结构体 struct OpenChaoJi_evcc_hal_samp 的指针。移植者需要分别填充其 voltage_in、voltage_out 和 current 成员。
  • 返回值：
    • 0：采样读取成功。
    • -1：采样失败。
  • 移植说明：
    此接口直接提供闭环控制所需的物理数值。移植者需要读取高压采集电路（如高压分压采样、数字传感器输入等）的值并存入结构体：
    • voltage_in 对应电池包内部端电压。
    • voltage_out 对应车辆充电插口外侧电压。
    • current 对应当前的实际充电电流。
