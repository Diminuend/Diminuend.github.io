方法一：直接重新生成加密密码并替换（最快，推荐）

你可以利用一个临时的 Docker 容器，让 Rclone 帮你把新密码“加密”，然后手动替换到配置文件中。

1. 生成加密后的新密码
在宿主机终端执行以下命令（请把 '你的新密码' 替换为你真实的 WebDAV 新密码，保留单引号以防密码中有特殊字符）：

注：这个命令会临时下载 rclone，加密完密码后会立刻销毁容器，不留垃圾。

执行后，终端会输出一串类似这样的加密字符串：
Ex2V_kK_L_xxxxxx_yyyyyy_zzzzzz
复制这串加密字符串。

2. 修改配置文件
打开你的 rclone 配置文件：

找到 [my_webdav] 下面的 pass = ... 这一行。
将等号后面的旧内容删除，粘贴你刚刚复制的新的加密字符串。

3. 保存并退出
按 Ctrl+O，回车，再按 Ctrl+X。

方法二：通过配置向导修改（如果你不喜欢复制粘贴）

你也可以用 Docker 挂载你的配置文件，直接进入 Rclone 的配置向导来修改。

1. 运行配置向导
在宿主机输入以下命令：

2. 在向导中操作

  1. 终端会出现菜单，输入 e (Edit existing remote) 来编辑已有的配置。
  2. 输入你要修改的名字：my_webdav
  3. 接下来它会一项一项问你是否要修改（比如 url, vendor, user 等）。一直按回车键（保持默认），直到看到密码提示：
    Edit password? (y/n)
  4. 输入 y (Yes)。
  5. 输入 y 选择自己输入密码。
  6. 输入你的 新 WebDAV 密码（输入时屏幕不会显示，输完回车），并再次输入确认。
  7. 后面的选项继续一直按回车，直到回到主菜单。
  8. 输入 q 退出。
