Proxmox AIO 实践：LXC 环境下 Docker 版 Syncthing 与 Samba 共享方案

发表于2026-05-08|更新于2026-05-08|杂项知识

0. 背景与架构

在 AIO（All-In-One）主机中，我们需要一个 7x24 小时运行的同步服务（Syncthing），并将同步的数据实时共享给 Windows 虚拟机或物理机使用。

技术栈：

  • 宿主机： Proxmox VE (PVE)
  • 容器： LXC (运行 Docker)
  • 服务： Docker 版 Syncthing + 原生 Samba
  • 客户端： Windows 10/11 (通过 SMB 挂载)

逻辑架构：
PVE 虚拟硬盘 -> LXC 挂载点 (/mnt/storage) -> Docker (Syncthing 映射) & Samba (共享给 Windows)

1. 准备阶段：PVE 分配虚拟硬盘

在 PVE 界面中，为运行 Docker 的 LXC 容器添加一块独立的虚拟硬盘。

  1. 登录 PVE 管理界面，选择 LXC 容器（如 ID: 101）。
  2. 进入 Resources (资源) -> Add (添加) -> Mount Point (挂载点)。
  3. 配置：
    • Storage: 选择存储池（如 local-lvm）。
    • Disk size: 按需设置（例如 500G）。
    • Path: 设置为 /mnt/storage（LXC 内部路径）。
  4. 确认添加。

  1. 打开浏览器访问 http://LXC_IP:8384。
  2. 添加/编辑文件夹时，“文件夹路径” 必须设置为容器内的映射路径：
    • 正确示例： /var/syncthing/my_sync_folder
    • 错误示例： /mnt/storage/...（这会导致数据写进容器层而非虚拟硬盘，容器重启数据丢失）。

7. 总结：下一次部署的避坑 Checklist

  1. 内外路径： Syncthing 网页里的路径必须是 /var/syncthing/...。
  2. 强制权限： Samba 配置里必须写 force user = root。
  3. 服务状态： 确保 systemctl status smbd 是 active。
  4. Windows 凭据： 推荐在“控制面板 -> 凭据管理器”手动添加登录信息，防止连接不稳定。
